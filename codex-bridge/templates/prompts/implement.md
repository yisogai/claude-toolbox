# 実装依頼（Claude Code から Codex への委譲）

リポジトリルートの `AGENTS.md` の規約に従うこと。特に **範囲外を変更しない**・**禁止事項**・
**最終メッセージの形式**（`## 結果:` から始まる見出し構成）を厳守する。質問して止まらず、
解釈の余地がある点は「〜と解釈した」と明示して進める。

## 目的
{{OBJECTIVE}}

## 範囲（ここだけを変更する）
{{SCOPE}}

## 非目標（やらない。気づいた点は「提案（未対応）」に書く）
{{NON_GOALS}}

## 受入条件（実際に検証してから完了と言う）
{{ACCEPTANCE}}

## 禁止事項（AGENTS.md に加えて、この依頼固有のもの）
{{FORBIDDEN}}

## 参考情報・現状のコンテキスト
{{CONTEXT}}

---

最終メッセージは必ず次の見出しをこの順で含めること（統括側が機械的に読む）:

```
## 結果: 完了 | 一部完了 | 失敗
## 変更ファイル
## 実行した検証
## 受入条件の充足
## 未検証・仮定
## 提案（未対応）
```
